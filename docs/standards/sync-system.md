# Doxus 동기화 시스템 가이드 (Sync System Guide)

Doxus는 사용자의 지식을 언제나 최신 상태로 유지하면서도, 시스템 리소스와 외부 서비스의 안정성을 보장하기 위해 지능적인 동기화 엔진을 사용합니다.

## 1. 동기화 트리거 (Sync Triggers)

Doxus는 다음과 같은 상황에서 동기화를 수행합니다.

### 1-1. 실시간 동기화 (Real-time Watcher)
- **발생 시점**: 사용자가 로컬 파일을 수정하고 저장할 때 즉시 감지합니다.
- **안전장치**: 
    - **노이즈 필터링**: `.obsidian`, `.git` 등 시스템 폴더와 설정 파일의 변경은 무시합니다.
    - **연속 저장 보호**: 2초 내에 발생하는 다중 저장 이벤트는 하나로 묶어 처리합니다.

### 1-2. 포커스 동기화 (On-Focus Sync)
- **발생 시점**: 다른 앱을 사용하다가 Doxus 앱 창을 클릭하거나 전환했을 때 발생합니다.
- **차등 쿨다운(Differentiated Cooldown)**:
    - **로컬 소스 (Obsidian 등)**: 1분의 쿨다운을 적용합니다.
    - **외부 소스 (Confluence, GitHub 등)**: API 보호를 위해 15분의 쿨다운을 적용합니다.

### 1-3. 주기적 동기화 (Periodic Sync)
- **발생 시점**: 설정된 시간 간격(예: 2시간)마다 백그라운드에서 실행됩니다.
- **목적**: 실시간 감지나 포커스 동기화에서 놓칠 수 있는 변경사항을 최종적으로 보정합니다.

### 1-4. 수동 동기화 (Manual Sync)
- **발생 시점**: 사용자가 프로젝트 관리 페이지에서 직접 '인덱싱' 버튼을 누를 때 발생합니다.
- **특징**: 모든 제한 사항을 우회하고 즉시 전체 스캔을 수행합니다.

## 2. 동기화 기술 및 최적화

### 2-1. 스마트 인덱싱 (Smart Update)
동기화가 트리거되더라도 문서의 내용(Content Hash), 제목, URL 등이 실제로 바뀌지 않았다면 DB의 "Last Indexed" 타임스탬프를 갱신하지 않습니다. 이를 통해 사용자에게 실제 정보가 변경된 시점만을 정확히 제공합니다.

### 2-2. 배치 처리 (Batch Fetching)
Confluence와 같은 외부 서비스를 동기화할 때, 변경된 문서들을 하나씩 API로 요청하지 않고 **최대 25개씩 묶어서(Batch)** 요청합니다. 이 방식은 다음의 이점을 제공합니다.
- **성능**: 네트워크 왕복 횟수를 90% 이상 줄여 동기화 속도를 획기적으로 개선합니다.
- **안정성**: 외부 서비스의 `Too Many Requests (429)` 에러 발생을 원천적으로 차단합니다.

### 2-3. 증분 동기화 (Incremental Sync)
전체 문서를 매번 새로 고치지 않고, 마지막 동기화 시점(`since`) 이후의 변경사항만 플러그인에 요청하여 작업량을 최소화합니다.

## 3. 지능적 제목 추출 (Intelligent Title Extraction)

문서 인덱싱 시 단순히 파일명을 사용하는 대신, 문서의 맥락을 가장 잘 나타내는 제목을 찾기 위해 다음과 같은 3단계 계층적 추출 전략을 사용합니다.

1.  **YAML Frontmatter (최우선)**: 문서 상단 프론트매터에 `title: "제목"` 필드가 명시되어 있다면 이를 가장 신뢰할 수 있는 제목으로 채택합니다.
2.  **Markdown Headers (차선)**: 프론트매터 제목이 없는 경우, 본문에서 가장 처음 나타나는 헤더(수준에 상관없이 `#`, `##`, `###` 등)를 찾아 제목으로 사용합니다.
3.  **File Name (기본값)**: 위 두 가지 방법으로 제목을 찾지 못한 경우에만 파일명(Extension 제외)을 제목으로 사용합니다.

이 정책을 통해 사용자는 문서 내부의 구조만으로도 Doxus 검색 결과의 가독성을 높일 수 있으며, "Untitled"와 같은 불명확한 제목 노출을 원천적으로 방지합니다.

---

## 4. 요약: 효율적인 문서 관리 가이드
- **빠른 반영**: 로컬 파일 수정 사항은 저장 즉시 검색에 반영됩니다.
- **안전한 외부 연동**: 외부 서비스는 15분 간격으로 안전하게 최신화됩니다.
- **신뢰할 수 있는 시간**: UI에 표시되는 인덱싱 시간은 "진짜로 데이터가 변했을 때"만 갱신되므로 안심하고 신뢰할 수 있습니다.
